# Results

Committed benchmark artifacts live here, one directory per model:

```
results/<Model-Name>/
├── results.json    # raw: host info, llama.cpp commit, run params, every row
├── report.md       # human-readable table + KleidiAI speedup
└── report.html     # standalone leaderboard (screenshot this for the demo)
```

These are generated by `kleidibench run <model>` / `kleidibench sweep <cfg>` on
the Arm box, then committed so judges can see real numbers without re-running.

_Populated after the first benchmarking run on the Oracle Ampere A1._
